# Focus-Timer
A lightweight, customizable Focus Timer and productivity web app with Pomodoro sessions, study analytics, monthly reports, ambient soundscapes, multiple background themes, fullscreen mode, and local data persistence. Built with HTML, CSS, and JavaScript with a strong focus on performance and distraction-free studying.
# Features
1.Focus, Short Break & Long Break
2.Study analytics with daily, weekly & monthly reports
3.Rain, Fire, Library & Piano ambience
4.Multiple sounds at once
5.Custom backgrounds
6.Fullscreen mode
7.Custom timer settings
8.Local data saving
9.Performance-focused design

# Run

Just open index.html in your browser, or host it with GitHub Pages.

# Tech

HTML • CSS • JavaScript • Web Audio API
